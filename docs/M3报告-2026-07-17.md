## 4. 保留的 Spree 引用（技术性，不去除）

以下引用属于技术性/API 级别，保留不变：

- `X-Spree-Channel` HTTP Header（API 协议）
- `SPREE_API_URL` / `SPREE_PUBLISHABLE_KEY` 环境变量名
- `@spree/sdk` npm 包名
- `spree_default` Docker 网络名
- `spree-web-1` 容器名
- `spree.png` Logo 图片文件（文件名保留，alt 属性已改为 PallasTrade）

---

## 5. 技术要点

- **构建参数**: Storefront Docker 构建需要 `--build-arg SPREE_API_URL=http://host.docker.internal:3000` 和 `SPREE_PUBLISHABLE_KEY`
- **无缓存构建**: 源码级更改（如 `store.ts`）需要 `--no-cache` 强制重建（Docker 的 `COPY . .` 层可能被缓存）
- **Admin Gem 内编辑**: `sed -i` 直接在容器内修改 gem 的 locale 和模板文件
- **重启生效**: Admin 容器修改后需 `docker restart` 才能重新加载模板
