## 1. 背景与目标

- **一句话需求原文**：新建店铺表单字段评估——能用已有数据预设/选择器的（如 currency）就不用手填。
- **背景**：
  1. 多店铺管理已上线（2026-08-17），新建店铺表单 `stores/new.html.erb` 共 9 个字段全部为手填文本，其中 `default_currency`/`supported_currencies`/`default_locale` 需要用户手写 ISO 代码（如 USD、en）——**普通用户最容易填错**（大小写/格式错误导致保存失败或配置错误）。
  2. 系统已有完整数据源：`::Money::Currency.all`（money gem 全部 ISO 货币）、`PallasTrade::Locales::ALL`（系统规范翻译语言集，edit 表单已在用）、当前登录用户邮箱、默认店铺值。
  3. 评估结论（已与用户确认）：name/code/url 无数据源必须手填；**货币/语言改选择器**；**邮箱字段可预设**。
- **目标**：
  1. `default_currency` 改为**下拉选择**（`::Money::Currency.all`，默认 USD）。
  2. `supported_currencies` 改为**多选**（全部 ISO 货币，默认勾选 USD）。
  3. `default_locale` 改为**下拉选择**（`PallasTrade::Locales::ALL`，默认 en）。
  4. `customer_support_email`/`new_order_notifications_email` 改为**预设当前登录用户邮箱**（可改）。
  5. `mail_from_address` 保持自动（按 url 生成）。
- **成功指标**：新建店铺从"手填 9 项"降到"必填手填 3 项 + 默认选择即可保存"；货币/语言零格式错误。

## 2. 用户故事 / 场景

- 作为**超管**，我希望新建店铺时货币/语言用下拉/多选，以便不用记忆 ISO 代码。
- 作为**超管**，我希望客服/通知邮箱自动带出我自己的邮箱，以便少填两项。
- 场景列表：
  - 正常流：新建页 → 货币下拉选中 USD（默认）→ 多选 USD+EUR → 语言下拉 en（默认）→ 邮箱已预设当前用户邮箱 → 填 name/code/url → 保存成功。
  - 边界：多选货币时未含默认货币 → 校验（default 必须在 supported 中？）或后端自动补。
  - 异常：预设邮箱留空（当前用户无邮箱）→ 字段仍可手填。

## 3. 功能需求（FR）

- FR-001：`default_currency` 改为下拉选择（数据源 `::Money::Currency.all`，默认 USD）。
- FR-002：`supported_currencies` 改为多选（数据源同上，默认选中 default_currency）。
- FR-003：`default_locale` 改为下拉选择（数据源 `PallasTrade::Locales::ALL`，默认 en）。
- FR-004：`customer_support_email`/`new_order_notifications_email` 预填当前登录用户邮箱（controller 预设，可修改）。
- FR-005：`mail_from_address` 保持自动生成（`no-reply@<url>`）。
- FR-006：表单布局优化：必填（name/code/url）与可选（邮箱/货币/语言）分区，可读性提升。

## 4. 非功能需求（NFR）

- 可用性：选择器可搜索（货币 100+ 项、语言多项）；默认值合理。
- 兼容：`supported_currencies` 存储格式仍为逗号分隔字符串（后端不变）；`permitted_create_params` 兼容数组→join 转换。
- 可维护：货币/语言数据源单一（money gem / `PallasTrade::Locales::ALL`），不硬编码清单。
- 可测试：选择器渲染 + 提交参数转换 + 预设邮箱断言。

## 5. 验收标准（AC，与测试一一映射）

- AC-001 ← FR-001：新建页 default_currency 为下拉，含 USD 且默认选中。
- AC-002 ← FR-002：supported_currencies 为多选，默认含 default_currency；提交多选后落库为逗号分隔。
- AC-003 ← FR-003：default_locale 为下拉，含 en 且默认选中。
- AC-004 ← FR-004：新建页 customer_support_email / new_order_notifications_email 预填当前登录用户邮箱；可修改。
- AC-005 ← FR-005：mail_from_address 空时仍按 url 自动生成（回归）。
- AC-006 ← NFR/兼容：提交创建成功（name/code/url + 默认选择）→ 店铺创建且配置正确；全量回归零失败。

## 7. 技术影响

- **视图**：`views/pallastrade/admin/stores/new.html.erb` —— `default_currency` 改 `select`（`::Money::Currency.all`），`supported_currencies` 改多选 checkbox/select（提交数组），`default_locale` 改 `select`（`PallasTrade::Locales::ALL`）；邮箱字段预填；表单分区。
- **控制器**：`stores_controller#new` 预填邮箱（`try_pallastrade_current_user.email`）；`permitted_create_params` 支持 `supported_currencies` 数组 → `join(',')`（参考现有 `normalize_supported_currencies` 逻辑）；货币/语言默认值。
- **i18n**：新增 `admin.stores.currency`/`languages` 等标签（en + zh-CN）。
- **Spec**：`stores_multi_spec.rb` 增加选择器渲染 + 多选提交 + 邮箱预设断言。
- **无 DB 迁移；无 API 变更**；storefront/platform 不涉及。
