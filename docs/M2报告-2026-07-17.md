## 3. 完成事项

### 3.1 Storefront Docker 构建与部署

- **Dockerfile**: 多阶段构建（deps → builder → runner）
- **基础镜像**: `node:22-alpine`
- **构建参数**: `SPREE_API_URL`, `SPREE_PUBLISHABLE_KEY`
- **编译**: Next.js 16.2.6 (Turbopack)，~23s
- **关键修复**: 运行时需通过 `-e` 传递环境变量（runner 阶段不含构建时 ARG）
- **网络**: 加入 `spree_default` 网络以访问 Backend
