## 3. Docker 重建与部署

```bash
# 构建 (--no-cache --pull 确保全新编译)
docker build --no-cache --pull \
  --build-arg SPREE_API_URL=http://host.docker.internal:3000 \
  --build-arg SPREE_PUBLISHABLE_KEY=pk_Zgvn9hqjXHPQCfgGJNbuRzNY \
  -t pallastrade-storefront d:\pallastrade\storefront

# 部署
docker stop pallastrade-storefront && docker rm pallastrade-storefront
docker run -d -p 3001:3001 --name pallastrade-storefront \
  --network spree_default \
  -e SPREE_API_URL=http://spree-web-1:3000 \
  -e SPREE_PUBLISHABLE_KEY=pk_Zgvn9hqjXHPQCfgGJNbuRzNY \
  pallastrade-storefront
```
