# Maintenance Policy

This extension scaffold is maintained by its repository owner. It does not
solicit or accept external code contributions or pull requests.

## Reporting Issues

Use the repository's issue tracker for reproducible bug reports and feature
requests. Do not disclose security vulnerabilities in a public issue.

## Maintainer Changes

The maintainer should:

- work on a focused topic branch;
- make logical commits with clear imperative messages;
- add tests for behavior changes and bug fixes;
- run the complete relevant test and lint suite;
- verify `git diff --check` before merging;
- merge into the repository's protected default branch only after checks pass.

This policy does not require a Contributor License Agreement because external
code contributions are not accepted.
