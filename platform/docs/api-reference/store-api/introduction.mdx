This API reference includes PallasTrade Store APIs, which are REST APIs exposed by the PallasTrade application. They are used to create a storefront for your commerce store, such as a website, point of sale or a commerce mobile app.

All API Routes are prefixed with `/api/v3/store`. So, during development, the API Routes will be available under the path `http://localhost:3000/api/v3/store`. For production, replace `http://localhost:3000` with your PallasTrade application URL.

## Using SDK

We recommend using the PallasTrade SDK to interact with the Store API. The SDK provides a convenient way to make API requests and handle responses.

### Installation

```bash
npm install @pallastrade/sdk
# or
yarn add @pallastrade/sdk
# or
pnpm add @pallastrade/sdk
```

### Quick Start

```typescript
import { createClient } from '@pallastrade/sdk';

// Initialize the client
const client = createClient({
  baseUrl: 'http://localhost:3000',
  publishableKey: 'pk_xxx'
});
```
