<Warning>
  This guide is aimed at advanced users who want to add PallasTrade to an existing Rails application. If you are new to PallasTrade, please follow the [Quickstart guide](/getting-started/quickstart).
</Warning>

## Overview

If you already have a Ruby on Rails application, you can add PallasTrade to it by following these steps.

<Info>
  PallasTrade works with **PostgreSQL**, **MySQL**, and **SQLite** — whatever database your Rails app already uses. No database migration is needed.
</Info>

## 1. Add PallasTrade gems

Add these lines to your project `Gemfile`:

```ruby
pallastrade_opts = { 'github': 'stevenbian9266-cyber/pallastrade', 'branch': 'main' }
gem 'pallastrade', pallastrade_opts # core, API, and CLI
gem 'pallastrade_admin', pallastrade_opts # Admin panel (optional)
gem 'pallastrade_emails', pallastrade_opts # transactional emails (optional)
```

And run the following command to install the gems:

```bash
bundle install
```

## 2. Run the install generators

PallasTrade uses a modular installation approach. First install the core, then add optional components.

### Install core PallasTrade

This installs core models, API, CLI, and authentication:

```bash
bin/rails g pallastrade:install --user_class=PallasTrade::User --authentication=devise
```

**Core installation options:**

| Option | Description |
|--------|-------------|
| `user_class` | The class for your users, eg. `PallasTrade::User` or `User` |
| `admin_user_class` | The class for admin users (defaults to `user_class`) |
| `authentication` | Authentication gem: `devise` or `custom` |
| `migrate` | Whether to run migrations (default: true) |
| `seed` | Whether to run the seed file (default: true) |
| `sample` | Whether to add sample data (default: false) |
| `admin_email` | Email of the first admin user |
| `admin_password` | Password of the first admin user |

### Install Admin Panel (optional)

```bash
bin/rails g pallastrade:admin:install
bin/rails g pallastrade:admin:devise  # if using Devise authentication
```

### Add sample data (optional)

To add sample data to your store, run:

```bash
bin/rake pallastrade:load_sample_data
```

This will add some products, categories and multiple markets to your store.

## Accessing Admin Panel

Navigate to [http://localhost:3000/admin](http://localhost:3000/admin) and log in with the default credentials:

| | |
|---|---|
| **Email** | `pallastrade@example.com` |
| **Password** | `pallastrade123` |
