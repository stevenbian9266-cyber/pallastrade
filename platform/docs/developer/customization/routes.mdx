## Default configuration

By default PallasTrade is mounted at the root of your domain, this code will be inserted into `config/routes.rb`:

```ruby
mount PallasTrade::Core::Engine, at: '/'
```

This means that PallasTrade will be available at the root of your domain, for example `http://localhost:3000`.

## Customizing the mount point

You can customize this simply by changing the `:at` specification in `config/routes.rb` to be something else. For example, if you would like PallasTrade to be mounted at `/shop`, you can write this:

```ruby
mount PallasTrade::Core::Engine, at: `/shop`
```

The different parts of PallasTrade (API, Admin) will be mounted there as well, eg. `http://localhost:3000/shop/products`.
