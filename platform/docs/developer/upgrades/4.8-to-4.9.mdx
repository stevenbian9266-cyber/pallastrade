---

<Info>
  Before proceeding to upgrade, please ensure you're at [PallasTrade 4.8](/developer/upgrades/4.x-to-4.8)
</Info>

## Upgrade steps

### 1. Update gems

```bash
bundle update
```

### 2. Install and run missing migrations

```bash
bin/rake pallastrade:install:migrations && bin/rails db:migrate
```

## Read the release notes

For information about changes contained within this release, please read the [PallasTrade 4.9.0 Release Notes.](https://github.com/orgs/pallastrade/discussions/12123)
