## Update gems

```bash
bundle update
```

## Copy and run migrations

Copy over the migrations from PallasTrade and any other engine and run them using these commands:

```bash
rake railties:install:migrations
rake db:migrate
```

## Additional information

### Migrate custom API templates

Custom templates and overrides from this historical release line are not loaded
by the current API. Reimplement them against the API v3 serializers and routes.

### Remove `PallasTrade::Config.check_for_pallastrade_alerts`

If you were disabling the alert checks you'll now want to remove this preference from `config/initializers/pallastrade.rb` as it's no longer used.
