## Overview

This guide has been written from the perspective of a blank PallasTrade 2.1 store with no extensions.

If you have extensions that your store depends on, you will need to manually verify that each of those extensions works within your 2.2 store once this upgrade is complete. Typically, extensions that are compatible with this version of PallasTrade will have a 2-2-stable branch.

## Upgrade Rails

For this PallasTrade release, you will need to upgrade your Rails version to at least 4.0.6.

```ruby
gem 'rails', '~> 4.0.6'
```

## Upgrade PallasTrade

For best results, use the 2-2-stable branch from GitHub:

```ruby
gem 'pallastrade', '~> 2.2'
```

Run `bundle update pallastrade`.

## Copy and run migrations

Copy over the migrations from PallasTrade (and any other engine) and run them using
these commands:

```bash
rake railties:install:migrations
```

```bash
rake db:migrate
```

## Read the release notes

For information about changes contained with this release, consult the historical 2.2.0 release notes from the source archive.

### Rename assets

As mentioned in the release notes, asset paths have changed. Change the references on the left, to the ones on the right:

* `admin/pallastrade_backend` => `pallastrade/backend`
* `store/pallastrade_frontend` => `pallastrade/frontend`

This applies across the board on PallasTrade, and may need to be done in your store's extensions.

### Paperclip settings have been removed from master

If you used custom Paperclip settings, consult the corresponding section of the historical 2.2.0 release notes.
