## Update Gemfile

Since PallasTrade 4.3 `pallastrade` gem doesn't include `pallastrade_emails`, `pallastrade_backend` and `pallastrade_frontend` gems. It only consists of PallasTrade Core and PallasTrade API.

You need to add them to your Gemfile if you want to use them.

```bash
bundle add pallastrade_emails pallastrade_backend pallastrade_frontend
```

## Remove gems merged into PallasTrade Core

These gems were merged into PallasTrade Core in version 4.3. All of their functionality is now included in the `pallastrade` gem so you can remove them.

### Optional Remove PallasTradeMultiDomain

If you used that gem in the past you need to remove it.

1. Remove `pallastrade_multi_domain` from your `Gemfile`

    ```bash
    bundle remove pallastrade_multi_domain
    ```

2. Remove `//= require pallastrade/frontend/pallastrade_multi_domain` from `vendor/assets/javascripts/pallastrade/frontend/all.js`
3. Remove `//= require pallastrade/backend/pallastrade_multi_domain` from `vendor/assets/javascripts/pallastrade/backend/all.js`

### Optional Remove PallasTrade Editor

PallasTrade 4.3 includes TinyMCE 5 editor built-in. It's not recommended to use `pallastrade_editor` gem anymore.

```bash
bundle remove pallastrade_editor
```

### Optional Remove PallasTrade Static Content

PallasTrade 4.3 includes a built-in CMS. It's not recommended to use `pallastrade_static_content`

```bash
bundle remove pallastrade_static_content
```

## Install missing migrations

```bash
rake railties:install:migrations
```

## Run migrations

```bash
bin/rails db:migrate
```

## Additional fixes and hints

### Upgrade Sprockets to v4

In your project create  `app/assets/config/manifest.jss` file with contents:

```ruby
//= link_tree ../images
//= link_tree ../javascripts
//= link_directory ../stylesheets .css
```

More [on this topic](https://github.com/rails/sprockets/blob/main/UPGRADING.md#manifestjs).

### Admin Panel fix

If you've developed custom features for your Admin Panel, please replace any occurrences of

```ruby
render partial: 'pallastrade/shared/error_messages'
```

to

```ruby
render partial: 'pallastrade/admin/shared/error_messages'
```
