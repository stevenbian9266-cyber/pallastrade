This guide has been written from the perspective of a blank PallasTrade 2.3 store with no extensions.

If you have extensions that your store depends on, you will need to manually verify that each of those extensions works within your 2.4 store once this upgrade is complete. Typically, extensions that are compatible with this version of PallasTrade will have a 2-4-stable branch.

## Upgrade Rails

For this PallasTrade release, you will need to upgrade your Rails version to at least 4.1.8.

```ruby
gem 'rails', '~> 4.1.8'
```

## Upgrade PallasTrade

```ruby
gem 'pallastrade', '~> 2.4'
```

Run `bundle update pallastrade`.

## Copy and run migrations

Copy over the migrations from PallasTrade (and any other engine) and run them using
these commands:

```bash
rake railties:install:migrations
```

```bash
rake db:migrate
```
