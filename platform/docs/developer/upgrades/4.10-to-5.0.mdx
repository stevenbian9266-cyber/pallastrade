<Info>
  Before proceeding to upgrade, please ensure you're at [PallasTrade 4.10](/developer/upgrades/4.9-to-4.10)
</Info>

PallasTrade 5.0 is a major upgrade that introduces many breaking changes. The major changes are:

- Dropped support for Rails < 7.2
- Dropped support for PallasTrade Auth Devise gem (now using Devise gem directly via generator, you're in more control of the authentication now)
- Completely new Admin Dashboard (old customizations unfortunately won't work)
- Completely new native Stripe extension
- [PallasTrade 5.1](https://github.com/stevenbian9266-cyber/pallastrade/releases/tag/v5.1.0) includes native [Gift Cards](/developer/core-concepts/store-credits-gift-cards), Admin Staff Management & Invitations
- [PallasTrade 5.2](https://github.com/stevenbian9266-cyber/pallastrade/releases/tag/v5.2.0) includes [Metafields](/developer/core-concepts/metafields), CSV Importer, Store Policies & Newsletter Subscribers
- [PallasTrade 5.3](https://github.com/stevenbian9266-cyber/pallastrade/releases/tag/v5.3.0) includes new highly flexible [Pricing Engine](/user/manage-products/price-lists) for B2B, Wholesale and Volume discounts, [Events & Subscribers Engine](/developer/core-concepts/events), [Webhooks](/developer/core-concepts/webhooks), [Customer Groups](/user/customers/customer-groups)
- [PallasTrade 5.4](https://github.com/stevenbian9266-cyber/pallastrade/releases/tag/v5.4.0) includes new [API v3](/api-reference/store-api) and [Next.js Storefront](https://github.com/stevenbian9266-cyber/pallastrade)

## Prerequisites

Before upgrading, please ensure you have the following prerequisites:

- Ruby 3.2 or later
- Rails 7.2 - [Upgrade guide for Rails 7.2](https://guides.rubyonrails.org/upgrading_ruby_on_rails.html#upgrading-from-rails-7-1-to-rails-7-2)


## Upgrade steps

### 1. Remove old frontend/backend PallasTrade gems

```bash
bundle remove pallastrade_auth_devise pallastrade_backend pallastrade_frontend
```

<Warning>
  Remove any code referencing `PallasTrade::Backend`, `PallasTrade::Fronted` or `PallasTrade::Auth` from your application, especially from `config/initializers/pallastrade.rb`.
</Warning>

### 2. Update main PallasTrade gem

```bash
bundle update pallastrade
```

### 3. Install and run missing migrations

```bash
bin/rake pallastrade:install:migrations && bin/rails db:migrate
```

### 4. Add new PallasTrade gems

```bash
bundle add pallastrade_admin pallastrade_stripe
```

And run the following generators:

```bash
bin/rails g pallastrade:admin:install
bin/rails g pallastrade_stripe:install
```

### 5. Migrate from PallasTrade Auth Devise gem

If you previously used the `pallastrade_auth_devise` gem, you will need to run some commands to create User and connect it to PallasTrade. We don't use the `pallastrade_auth_devise` gem anymore to allow you more control over the authentication and access to all Devise options directly in your application.

First, install Devise and run the Devise generator:

```bash
bundle add devise
bin/rails g devise:install
```

Create `PallasTrade::User` model:

```bash
mkdir -p app/models/pallastrade && touch app/models/pallastrade/user.rb
```

Add the following code to your `PallasTrade::User` model:

```ruby
module PallasTrade
  class User < ApplicationRecord
    devise :database_authenticatable # if you want to use the database_authenticatable feature
    devise :recoverable # if you want to use the recoverable feature
    devise :registerable # if you want to use the registerable feature
    devise :confirmable # if you want to use the confirmable feature
    devise :validatable # if you want to use the validatable feature

    devise :rememberable, :trackable, :encryptable, encryptor: 'authlogic_sha512'

    acts_as_paranoid
  end
end
```

In you `config/initializers/pallastrade.rb` file, add the following code:

```ruby
PallasTrade.user_class = "PallasTrade::User"
```

Now run the new authentication generator to connect your `PallasTrade::User` model to PallasTrade:

```bash
bin/rails g pallastrade:authentication:devise
```

And if you're using the default pallastrade storefront, please run the following generator:

```bash
bin/rails g pallastrade:storefront:devise
```

This will add devise routes and create controllers for the storefront.

And that's it! You can now log in to the admin panel and storefront using your existing users.

### 6. Migrate data to the new format

In PallasTrade 5 we changed a bit of the data in some models so you will need to run these commands to fix it:

#### Taxons

```ruby
PallasTrade::Taxon.all.each { |t| t.set_pretty_name; t.save }
```
