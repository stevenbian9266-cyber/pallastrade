---
title: Repository maintenance policy
description: PallasTrade ownership, support channels, and external contribution policy.
---

PallasTrade is maintained exclusively by Steven Bian. The repository does not
accept external code contributions or pull requests.

## Bug reports and feature requests

Use the
[PallasTrade issue tracker](https://github.com/stevenbian9266-cyber/pallastrade/issues)
for public bug reports and feature requests. External pull requests will be
closed without review.

## Security reports

Do not report security vulnerabilities through a public issue, discussion, or
pull request. Send them privately to
[stevenbian9266@gmail.com](mailto:stevenbian9266@gmail.com).

## Internal maintenance

Only the maintainer may change the canonical repository. Internal changes must
pass the repository CI and release gates before they are merged into `main`.
PallasTrade does not use a Contributor License Agreement or external
contribution sign-off.

The [maintainer guide](developing-pallastrade) documents local setup and test
commands. The [extension guide](creating-an-extension) is for building private
extensions outside the maintained PallasTrade core.
