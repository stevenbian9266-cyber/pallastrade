FIN-P4-5（PRD-20260906-payments-fin-p4-5）：PaymentMethod#fetch_financial_details 只读契约（base default raise，镜像 fetch_payment_status）；PallasTradeStripe::Gateway 实现（cs_/pi_ 双模式→PI→latest_charge ch_→BalanceTransaction txn_(fee/net)→Refunds re_；金额 cents→元归一；settlement_status settled 仅当 PI succeeded，未捕获 fee/net nil 不猜）；retrieve_balance_transaction；Gateway::Bogus 确定性替身（completed→settled/fee0/net；本地 refunds 派生）；FinancialFacts::ProviderFinancialDetails transient VO（白名单 from_hash/freeze）；provider_reconciliation_capability 翻转（Stripe/Bogus→SUPPORTED；Adyen/PayPal→UNSUPPORTED；StoreCredit/Check→NOT_APPLICABLE）；fee/net=reconciliation fact 不进 Journal；快照不落表（P4-6）；只读零副作用；无 migration/API；全量 backend-rspec 0 failures

- Stripe cs_ 与 pi_ 模式 succeeded → 归一 snapshot（pi_/ch_/txn_/re_ refs + gross + fee/net + refund_total + settlement=settled）
