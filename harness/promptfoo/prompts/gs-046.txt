# Eval Scenario GS-046: TXN-P2-6 轮3 storefront transaction-first 迁移

storefront 订单域支付入口从 payment-session-first 迁移到 transaction-first（P2 §42/§57）：checkout/start BFF 与 lib/data/order-payment 的会话创建改走 SDK orders.transactions.create（后端 Transactions::Start 冻结快照 + 绑定 payment execution），payment_execution 作为会话供 Provider UI；PATCH complete 仍走 orders.paymentSessions.complete；quote 冲突（quote_changed/checkout_version_conflict）提示并刷新 view 不自动支付；Provider UI 独立。
