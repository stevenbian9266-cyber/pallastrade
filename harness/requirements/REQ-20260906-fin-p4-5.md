## 需求标题

FIN-P4-5：Stripe Provider Financial Facts——fetch_financial_details（PI/Charge/BalanceTransaction/Refund 归一快照，只读）+ ProviderFinancialDetails VO + capability 翻转。

## 任务类型

新功能（core 契约/VO/capability + Stripe gem 只读实现 + Bogus 替身；**无 migration/API/UI**）

## 需求描述

实现只读 provider 财务明细契约：`PaymentMethod#fetch_financial_details(payment_session:)`（base default raise，镜像 fetch_payment_status）；core `ProviderFinancialDetails` transient VO（白名单 from_hash/freeze；gross/refund/fee/net/settlement/refs/observed_at，可空不猜）；`PallasTradeStripe::Gateway#fetch_financial_details`（cs_/pi_ 双模式 → PI → latest_charge(ch_) → BalanceTransaction(txn_) → refunds(re_)，fee/net 从 BT，gross/refund 归一，settlement_status 如实；新增只读 retrieve_balance_transaction + latest_charge id helper）；`Gateway::Bogus` 确定性替身；`CaptureEvidencePolicy.provider_reconciliation_capability` Stripe/Bogus → SUPPORTED（Adyen/PayPal UNSUPPORTED、StoreCredit/Check NOT_APPLICABLE）。fee/net 不进 Journal（reconciliation fact）；快照不落表（P4-6）。不改 Payment/Refund/Journal/PaymentFactResolver/fetch_payment_status。

## 影响范围

- 变更：core `payment_method.rb`(+契约)、`gateway/bogus.rb`(+替身)、`financial_facts/capture_evidence_policy.rb`(capability)；stripe gem `gateway.rb`(+retrieve_balance_transaction/charge helper)、`gateway/payment_sessions.rb`(+fetch_financial_details)；core 新 VO `financial_facts/provider_financial_details.rb`；specs（backend + stripe gem）+ skills/scenarios/PRD。
- 不改：Payment/Refund/session state machine、Journal 全家、Transactions::*、fetch_payment_status 路径；无 migration/schema；无 API/storefront/platform。

## 技术方案（初步）

见 PRD §7。关键：fetch_payment_status 契约对称；Stripe 金额 cents→元归一；settlement_status 归一并加入 :settled；capability 与实现存在一致；只读零副作用（spec 断言不发 mutation 调用）。

## 风险点

- 最高风险：Stripe 金额单位/币种误归一 → cents→decimal 转换 spec 强制；BT 缺失（未捕获）→ fee/net nil 不猜。
- 中风险：capability 与实现不一致（误标 SUPPORTED 但无实现）→ 以 respond_to/type 判定 + spec。
- 中风险：破坏 fetch_payment_status / PaymentFactResolver → 回归强证。
- 回滚难度：低（新增 VO/方法 + 翻转 1 capability；无 schema/既有行为变更）。
