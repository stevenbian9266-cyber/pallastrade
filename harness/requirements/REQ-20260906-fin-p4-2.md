## 需求标题

FIN-P4-2：CommerceTransaction 级不可变资金账本（FinancialLedgerEntry + 幂等 Posting + Reversal/Correction）。

## 任务类型

新功能（含 migration：新建 `pallastrade_financial_ledger_entries`；不改既有表/API/UI）

## 需求描述

在 FIN-P4-1 FinancialFact 之上建立不可变资金账本：新增 `financial_ledger_entries` 表（commerce_transaction 归属 + 显式 source FK + entry_type + 带符号 amount + currency + 唯一 idempotency_key + reversal 自引用 + state posted/reversed）；`FinancialLedgerEntry` 模型（append-only：amount/currency/source/entry_type/ownership 禁原地改 → ImmutableError）；`FinancialLedger::Post`（输入 = FIN-P4-1 CONFIRMED FinancialFact，幂等 + RecordNotUnique 兜底 + fact_posting_key 派生）；`FinancialLedger::Reverse`（追加冲销 + 原 entry → reversed + 重复保护）。entry_type 激活 CASH_CAPTURED/STORE_CREDIT_APPLIED/OFFLINE_PAYMENT_RECORDED/REFUND_SUCCEEDED（ORDER_ALLOCATION/PSP_FEE/PSP_NET_SETTLEMENT 预留不激活）。不接 Payment/Refund 事件挂钩（P4-3）、不接 PSP、无 API/UI。

## 影响范围

- 变更：core gem `app/models/`、`app/services/`、`db/migrate/` + `backend/db/migrate/`（复制）+ `backend/db/schema.rb`（自动）+ `backend/spec/**` 新增 + skills/scenarios/PRD。
- 不改：P0-P3/P4-1 任何既有行为、Payment/Refund/PaymentSplit/OrderUpdater、API、storefront/platform。

## 技术方案（初步）

见 PRD §7（表结构冻结 + FinancialLedgerEntry/Post/Reverse 设计）。命名纪律：`commerce_transaction_id`；`idempotency_key` UNIQUE；RecordNotUnique → 重查返回（幂等）。

## 风险点

- 最高风险：不可变约束被绕过（update 历史）→ ImmutableError 拦截 + spec 强制。
- 中风险：幂等 key 派生不唯一 → UNIQUE 约束 + fact_posting_key 单测。
- 回滚难度：低-中（新表 + 新文件；drop 新表/删文件即可；无既有变更）。
