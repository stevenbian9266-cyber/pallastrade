## 技术方案（初步）

1. CheckoutView TS interface 字段与 CheckoutSerializer/既有 Order type 对齐；items 复用既有 `LineItem` type（serializer 同源）；money 字段 string | null + display_*。
2. `orders.checkout.get` request 类型：`CheckoutView`；path `/orders/${orderId}/checkout`。
3. page.tsx or_ 分支：`const [order, view] = await Promise.all([getOrderForCheckout(id), getOrderCheckout(id)])`（view 为 null 时回退 order 快照，防端点抖动）→ 传 `order` + `view`。
4. OrderPaymentContent：props 增 `view?: CheckoutView | null`；summary/address 取 view（fallback order）；`const ready = view?.ready ?? true`；`!ready` → Pay disabled + missing 提示。
5. 死代码删除前 `grep submitCartOrder|submitCartAndGoToCheckout` 全 storefront 确认 0 调用。
