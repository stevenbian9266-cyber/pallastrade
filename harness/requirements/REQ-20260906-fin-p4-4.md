## 需求标题

FIN-P4-4：Allocation Integrity —— PaymentSplit → ORDER_ALLOCATION 不可变入账 + split/allocation sum invariant（P4 拆包第 4 包）。

## 任务类型

新功能（core gem：FinancialFact 契约扩展 + resolver + Post 激活/回填 + 编排 + subscriber 注册；**无 migration/API/UI**）

## 需求描述

把组合支付 PaymentSplit 的订单归属作为不可变 ORDER_ALLOCATION 记入资金账本并闭环恒等式：扩展 FinancialFact（+payment_split_id 属性、+ORDER_ALLOCATION fact type、allocation? helper）；新增只读 `FinancialFacts::ResolveAllocation`（split → ORDER_ALLOCATION fact：order_id/split/captured_amount/currency + combination.commerce_transaction ownership；captured=0/无组合/组合无 txn → 不可 post 不猜）；`FinancialLedgerEntry` 激活 ORDER_ALLOCATION（RESERVED 留 PSP_FEE/NET）；`FinancialLedger::Post` create_entry 回填 payment_split；新增 `FinancialLedger::{PostAllocation, PostCombinationAllocations, AllocationIntegrity}`（编排幂等——显式稳定 key `fact:ORDER_ALLOCATION:#{txn}:#{split}` 不依赖 effective_at；Integrity 只读恒等式 balanced?）；接线 `payment_combination.succeeded` → `PaymentCombinationSucceededSubscriber`（engine 注册，async、幂等、rescue 日志）。ORDER_ALLOCATION = 资金归属投影 ≠ cash（类型隔离，AC-4013）；不改 OrderUpdater/PaymentSplit/Settlement/Carts 行为。

## 影响范围

- 变更：core gem `app/models/`（financial_fact.rb、financial_ledger_entry.rb）、`app/services/`（financial_facts + financial_ledger + subscribers）、`lib/pallastrade/core/engine.rb`（+1 注册）+ `backend/spec/**` + skills/scenarios/PRD。
- 不改：PaymentSplit/OrderUpdater/Settlement/Complete/Carts::Complete/Transactions::Finalize/Refund；无 migration/schema；无 API/storefront/platform。

## 技术方案（初步）

见 PRD §7。关键决策：显式稳定幂等 key（FR-4P4-05）；trigger = payment_combination.succeeded async subscriber（Settlement 锁内先写 splits captured 再 succeed!——job 提交后读最终值）；legacy 无 txn 组合 → skip（P4-8 backfill）；effective_at 确定性（completed_at 优先）；Integrity 只读。

## 风险点

- 最高风险：ORDER_ALLOCATION 被误当 cash 计入聚合（双账 FIN-INV-05）→ entry_type 类型隔离 + spec 断言 cash 聚合不含 allocation（AC-4P4-03）。
- 中风险：重放/重试因 effective_at 变化产生重复 allocation → 显式稳定幂等 key（不依赖时刻）。
- 中风险：既有 P4-2 测试假设 ORDER_ALLOCATION 不可 post → 激活后改断言为可 post（正例）+ 保留 PSP_FEE 反例。
- 低风险：无 migration；回滚难度低（新增文件 + 激活 2 常量 + 注册 1 行 + create_entry 回填 1 行——均可还原）。
- 回滚难度：低。
