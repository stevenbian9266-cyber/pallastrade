## 任务类型

功能优化（CHK-P1-1A：Read-only Server-driven Checkout Projection）

## 需求描述

在现有 Order 域新增只读、无副作用、确定性投影：`PallasTrade::OrderCheckout::View.call(order:)` → CheckoutView DTO（金额只读 Order 权威列，禁止求和/重算/requote/retax/repricing/推进状态机）；新增 `Checkout Serializer` + `GET /api/v3/store/orders/:id/checkout`（复用 order_resolvable/customer/token 授权 + store isolation，v3 信封，沿用现有 money/hide_prices 契约）。不做：UpdateAddress/Contact/SelectShipping/ApplyPromotion/Refresh（→1B）、Version/PriceVersion/Expiration/Readiness/Snapshot（→P1-2/3）、Storefront/SDK（→P1-4）。无 DB migration；不改 Payment 链/Stripe/Carts::Complete/legacy 状态机/Storefront。

## 影响范围

- 新增（core）：`pallastrade_core/app/services/pallastrade/order_checkout/view.rb`（+DTO，Struct/Data/Result payload 按现有约定）
- 新增（api）：`checkout_controller.rb`（store orders 域）、`checkout_serializer.rb`（store v3）、routes 一条只读路由
- 修改：`backend/public/api-docs/store.yaml`、`ai/skills/pallastrade-checkout/SKILL.md`、`docs/checkout/CHK-P1-1A_ReadOnly_CheckoutView.md`、`docs/prd/README.md`
- DB：无 migration

## 技术方案（初步）

1. `OrderCheckout::View`：显式预加载（line_items+variants、addresses、shipments+shipping_rates、adjustments）；只读现有列；无副作用（不 touch/不 save/不 requote）。
2. DTO 字段集按 PRD FR-102（Identity/Order State/Items/Contact/Addresses/Shipping(existing only)/Discounts/Taxes/Price）；金额字段逐一映射 Order 权威列。
3. FR-103：不输出 version/price_version/expires_at/ready/missing（不用 updated_at.to_i 冒充）。
4. Serializer 只做格式化（prefix id、money 走现有 major-unit string、hide_prices 门控、nil/[] 语义）。
5. Controller 复用 order_resolvable；GET 无副作用。

## 风险点

- Legacy 在途订单 best-effort（nil/[]），不触发 next/advance/requirements（FR-108）。
- N+1 控制（NFR-104/AC-109）。
